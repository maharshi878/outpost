WHY OUTPOST

The interface. Not another middleman.

01 / LOCAL

Your key stays yours

Requests go directly to Resend. Outpost has no backend, account system, or telemetry.

02 / SIMPLE

One API key

Use your own Resend key. Sending-access keys work for sending; full-access keys unlock additional sync details.

03 / MULTI-PLATFORM

Desktop and Android

One project, with native desktop builds and an Android APK.

04 / PRIVATE

Credential protection

OS keychain on desktop and Android Keystore on Android. Read the security notes for platform-specific details.

05 / CONTROL

Know what you're sending

Usage checks, pacing, safe retries, and idempotency help prevent accidental duplicate sends.

06 / QUIET

No tracking pixels

Remote images are blocked and message content is sandboxed when rendered.

QUESTIONS

Frequently asked.

What is Outpost?

Outpost is a local-only email app for using your own Resend API key. It runs on desktop and Android.

Does Outpost send my API key to its own server?

Outpost has no application server. Requests go to Resend. Desktop credential handling uses the OS keychain where available; Android uses Android Keystore.

What platforms can I download it for?

Windows installers, macOS DMGs, Linux AppImages, and Android APKs are listed on GitHub Releases.

Is Outpost affiliated with Resend?

No. Outpost is an independent project and is not affiliated with Resend.

How do I receive replies?

Outpost suggests Cloudflare Email Routing. To read replies in Outpost itself, enable Resend receiving for a domain or subdomain.

Is it free and open source?

Outpost is MIT licensed. You use your own Resend account and API key.
