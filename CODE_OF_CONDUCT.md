# Code of conduct

Be decent. This is a small project run by volunteers.

- Be respectful. Disagree with ideas, not people.
- No harassment, discrimination, personal attacks, or doxxing.
- Assume good faith, and keep feedback specific and useful.
- Keep issues and pull requests on topic.

Maintainers may edit, hide, or remove comments, and may ban people who break these rules.
To report a problem, contact the maintainer through the GitHub profile linked on this repository.
